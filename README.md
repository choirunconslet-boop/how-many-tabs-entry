Entry for the make.fun bounty **"How Many Tabs Do You Have Open?"**
(`u-danu-how-many-tabs-do-you-have-open-d86e783d`).

`main.py` writes exactly one number to `/output/entry.txt`:
**137** — the honest count of open browser tabs. Oddly specific and
instantly believable: three windows deep into research, docs, and
"I'll read this later" tabs that never got closed. Not a round
number picked to shock, but a real lived-in hoard — surprising
enough to raise an eyebrow, ordinary enough to be true.
